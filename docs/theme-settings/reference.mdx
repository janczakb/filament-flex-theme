This is the complete current settings dictionary. Values are panel-wide. The
labels and UI-only helper fields in the editor are not additional saved keys.
Use [PHP configuration](/docs/theme-settings/configuration) for precedence and
[Panels and permissions](/docs/theme-settings/panels-permissions) for access.

The Default preset supplies `base_tint: 18`. Nullable native options retain
inheritance. Derived corner values are recomputed, not independently editable.

## Portable and nonportable values

Preference JSON includes the Appearance, Colors, Layout, Details, Search and
Keyboard keys above, plus `custom_fonts`. It omits Brand identity/paths and the
four derived corner values. `settingsOverrides()` accepts that portable set;
`settings()` can supply the complete validated theme configuration. Branding
paths must still be genuine generated panel-owned handles.

## Retired values and UI-only fields

Do not pass retired `content_width`, `border_style`, `shadow`, `density`, `glass`,
`sidebar_width`, `light_canvas`, `light_surface`, `light_text`, `dark_canvas`,
`dark_surface`, `dark_text`, `flex_fields`, `search_enabled`, or
`search_categories` as supported configuration. Use `max_content_width`, native
sidebar width configuration, derived tokens and the typed Search API instead.

`layout_variant`, `sidebar_mode`, `available_modes`, `default_mode`,
`show_theme_switcher`, `breadcrumbs_visible` and other editor helper fields map
to the real keys above. They are not public saved settings. Invalid or unknown
PHP/import keys fail validation instead of creating new theme behavior.
